# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/complydoc/complydoc/discussions).
- **Bugs and feature requests:** [GitHub issues](https://github.com/complydoc/complydoc/issues/new/choose).
  Search first; the issue forms ask for what we need to reproduce it.
- **Security vulnerabilities:** never in public. See [SECURITY.md](SECURITY.md).
- **Documentation:** [complydoc.io/docs](https://complydoc.io/docs/).

Support here is best effort, from the people who maintain complydoc. There is no response
time.

## Commercial support

[Veil](https://veil.complydoc.io/), by complydoc, offers support with response times,
help with deployment and rollouts for teams. complydoc stays open source either way: a
paid plan never takes a feature away from it.
